# Informe final en LaTeX

`main.tex` es la fuente vigente del informe final. Debe abrirse y compilarse
en Overleaf o en un entorno local con LaTeX antes de generar el PDF que se
entregará.

## Evidencias finales obligatorias

La sección `Resultados` de `main.tex` requiere exactamente estas dos capturas:

- `images/resultado-gabriel-landing.png` — landing pública interactiva de PoliLink.
- `images/resultado-darwin-admin-comunidades.png` — panel administrativo de solicitudes de comunidades.

Las capturas históricas de prototipos, Postman y avances anteriores se
conservan en `images/` como material de trabajo, pero ya no se referencian en
el informe final. Antes de compilar, agregar las dos capturas finales con los
nombres indicados y revisar sus captions.

La guía detallada para obtenerlas está en
[`CAPTURAS_FINALES.md`](CAPTURAS_FINALES.md).

## Imágenes históricas conservadas

Las imágenes `1-catalogo.png`, `2-descripcion.png`, `3_panel.png` y
`4-crearEvento.png` corresponden a prototipos iniciales. Las imágenes
`backend*.png` corresponden a evidencias históricas de la API. Las imágenes
`frontend-gabriel-*.png` y `frontend-darwin-*.png` corresponden a capturas de
implementaciones anteriores; ninguna debe reemplazar las dos evidencias
finales solicitadas.
